# Как запускать Excursions CRM

Инструкция рассчитана на macOS и уже настроенный проект. PHP, MySQL и Node.js отдельно запускать не нужно: приложение работает в Docker.

## Обычный запуск (каждый следующий раз)

1. Откройте **Docker Desktop** и дождитесь, пока Docker Engine запустится.
2. Откройте **Terminal** и перейдите в папку проекта:

   ```bash
   cd ~/Downloads/excursions-crm
   ```

   Если папка находится в другом месте, укажите её полный путь.

3. Запустите приложение и базу данных:

   ```bash
   bash vendor/laravel/sail/bin/sail up -d
   ```

4. Откройте в браузере [http://localhost](http://localhost).

Проверить состояние контейнеров можно командой:

```bash
docker compose ps
```

Когда закончите работу, остановите контейнеры:

```bash
bash vendor/laravel/sail/bin/sail down
```

Команда `down` сохраняет данные MySQL. При следующем запуске повторите шаги 1–4. Не добавляйте `-v` к `down`: ключ удалит Docker volume с базой данных.

## Первый запуск или настройка на новом компьютере

Выполняйте этот раздел один раз, если проект ещё не настроен на этом компьютере.

1. Установите и запустите Docker Desktop.
2. Перейдите в папку проекта и создайте `.env`, если его ещё нет:

   ```bash
   cd ~/Downloads/excursions-crm
   cp .env.example .env
   ```

3. В `.env` укажите параметры подключения к MySQL из Docker Compose: `DB_CONNECTION=mysql`, `DB_HOST=mysql`, имя базы, пользователя и пароль. Не публикуйте `.env` и не отправляйте его в репозиторий.
4. Установите зависимости PHP, если каталога `vendor` ещё нет:

   ```bash
   docker run --rm -u "$(id -u):$(id -g)" -v "$PWD:/app" -w /app composer:2 install
   ```

5. Соберите и запустите контейнеры:

   ```bash
   bash vendor/laravel/sail/bin/sail up -d --build
   ```

6. Подготовьте ключ приложения, структуру БД и фронтенд:

   ```bash
   bash vendor/laravel/sail/bin/sail artisan key:generate
   bash vendor/laravel/sail/bin/sail artisan migrate
   bash vendor/laravel/sail/bin/sail npm install
   bash vendor/laravel/sail/bin/sail npm run build
   ```

`key:generate` нужен при первичной настройке пустого `.env`; не запускайте его повторно в уже работающем проекте. Если миграция сообщает об ошибке, проверьте её состояние командой `bash vendor/laravel/sail/bin/sail artisan migrate:status`. Не используйте `migrate:fresh`: команда удалит все таблицы и данные.

## Если сайт не открывается

- Убедитесь, что Docker Desktop запущен.
- Проверьте контейнеры: `docker compose ps`.
- Посмотрите логи приложения: `bash vendor/laravel/sail/bin/sail logs -f laravel.test` (выход из просмотра — `Ctrl+C`).
- Перезапустите контейнеры: `bash vendor/laravel/sail/bin/sail down`, затем `bash vendor/laravel/sail/bin/sail up -d`.
- Если порт `80` уже занят, проверьте `APP_PORT` в `.env` и открывайте сайт на этом порту, например `http://localhost:8080`.

Подробные команды для Docker, Laravel и базы данных собраны в [справочнике команд](СПРАВОЧНИК_КОМАНД.md).

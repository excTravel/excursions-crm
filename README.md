# Excursions CRM

Веб-сервис для поиска, бронирования и управления экскурсиями. Проект разрабатывается в рамках курса **«Методы оптимизации в разработке программных решений»**.

## О проекте

**Excursions CRM** — веб-сервис, объединяющий клиентов, гидов и администраторов для удобной организации экскурсионной деятельности.

Основные возможности сервиса:

- **Клиенты** — поиск экскурсий и бронирование мест.
- **Гиды** — добавление собственных экскурсий и управление расписанием.
- **Администраторы** — модерация контента и контроль бронирований.

## Стек технологий

| Категория | Технология |
|---|---|
| Язык программирования | PHP 8.4 |
| Фреймворк | Laravel 11 + Livewire |
| База данных | MySQL 8.0 |
| Веб-сервер | Nginx (Laravel Sail) |
| Контейнеризация | Docker, Docker Compose |
| CI/CD | GitHub Actions |

## Запуск проекта

Для локального запуска проекта необходим установленный **Docker**.

1. Клонируйте репозиторий и перейдите в его корневую директорию.
2. Выполните команду для сборки и запуска контейнеров:

   ```bash
   docker compose up -d --build
   ```

3. После успешной сборки и запуска приложение будет доступно по адресу:

   [http://localhost](http://localhost)

### Остановка проекта

Для остановки контейнеров выполните:

```bash
docker compose down
```

# Реализация US-2: Вход в систему

## Задействованные компоненты
- Контроллер: `App\Http\Controllers\Auth\AuthenticatedSessionController`
- Модель: `App\Models\User`
- Представление: `resources/views/auth/login.blade.php`

## Логика работы
1. Пользователь вводит email и пароль на странице входа.
2. Контроллер валидирует введенные данные с помощью `LoginRequest`.
3. Проверяется соответствие email и пароля в базе данных.
4. Если данные верны, создается сессия (вызывается `Auth::attempt()`).
5. Сессия регенерируется для защиты от атак типа Session Fixation.
6. Пользователь перенаправляется на страницу дашборда.
7. Если данные неверны, выбрасывается исключение `ValidationException` с сообщением об ошибке.

## Безопасность
- Пароли хранятся в виде хешей (Bcrypt).
- Реализована защита от CSRF-атак через middleware `VerifyCsrfToken`.
- Сессия обновляется после успешного входа.

## Критерии приёмки (проверено)
- [x] Вход с правильными данными авторизует пользователя.
- [x] Вход с неправильными данными выдает ошибку валидации.
- [x] После входа происходит редирект на дашборд.
- [x] При выходе сессия уничтожается.

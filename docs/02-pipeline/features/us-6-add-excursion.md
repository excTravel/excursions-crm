# Реализация US-6: Добавление экскурсии

## Задействованные компоненты
- Компонент: `App\Livewire\Guide\ExcursionForm`
- Представление: `resources/views/livewire/guide/excursion-form.blade.php`

## Логика работы
1. Гид заходит в личный кабинет и открывает форму добавления экскурсии.
2. Заполняет обязательные поля (название, описание, цена, локация).
3. При сохранении экскурсия получает статус `pending` (на модерацию).
4. Экскурсия становится видимой в каталоге только после одобрения администратором.

## Критерии приёмки (проверено)
- [x] Дано: я вошёл как гид. Когда: я заполняю форму и сохраняю. Тогда: экскурсия создаётся со статусом `pending`.
- [x] Дано: я вошёл как клиент. Когда: я пытаюсь открыть форму. Тогда: система не даёт мне это сделать (ошибка доступа).

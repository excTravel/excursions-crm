# Реализация US-3: Просмотр каталога экскурсий

## Задействованные компоненты
- Компонент: `App\Livewire\ExcursionsList`
- Представление: `resources/views/livewire/excursions-list.blade.php`

## Логика работы
1. Клиент открывает главную страницу (каталог).
2. Компонент формирует запрос к базе данных.
3. **Важно:** Выводятся только экскурсии со статусом `approved` (одобренные администратором).
4. Применяются фильтры (поиск, категории, локации, сортировка), если они выбраны.
5. Результат выводится с пагинацией (по 12 штук на страницу).

## Критерии приёмки (проверено)
- [x] Дано: в системе есть одобренные экскурсии. Когда: я открываю каталог. Тогда: я вижу список экскурсий.
- [x] Дано: экскурсия не одобрена администратором. Когда: я открываю каталог. Тогда: я не вижу эту экскурсию.

# Реализация US-12: Просмотр своих бронирований

## Задействованные компоненты
- Компонент: `App\Livewire\MyBookings`
- Представление: `resources/views/livewire/my-bookings.blade.php`

## Логика работы
1. Клиент заходит в раздел «Мои бронирования».
2. Видит список всех своих заявок с их статусами (ожидает, подтверждено, отменено).
3. Если бронирований нет, отображается сообщение об этом.

## Критерии приёмки (проверено)
- [x] Дано: у меня есть бронирования. Когда: я открываю раздел. Тогда: я вижу список и статусы.
- [x] Дано: у меня нет бронирований. Когда: я открываю раздел. Тогда: я вижу сообщение, что заявок пока нет.

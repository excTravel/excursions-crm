# Реализация US-9: Создание бронирования

## Задействованные компоненты
- Компонент: `App\Livewire\ExcursionShow` (кнопка бронирования) и логика на бэкенде.
- Контроллер: `PaymentController` (для оплаты после брони).

## Логика работы
1. Клиент выбирает сеанс в расписании экскурсии.
2. Указывает количество участников.
3. Система проверяет наличие свободных мест.
4. Бронирование создается со статусом `pending` (ожидает подтверждения гида).

## Критерии приёмки (проверено)
- [x] Дано: я выбрал сеанс со свободными местами. Когда: я отправляю заявку. Тогда: бронирование создается.
- [x] Дано: на сеансе нет мест. Когда: я отправляю заявку. Тогда: бронирование не создается, я вижу ошибку.

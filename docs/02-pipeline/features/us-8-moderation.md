# Реализация US-8: Модерация экскурсий

## Задействованные компоненты
- Компонент: `App\Livewire\Admin\ExcursionsTable`
- Представление: `resources/views/livewire/admin/excursions-table.blade.php`

## Логика работы
1. Администратор заходит в панель управления.
2. Видит список экскурсий, ожидающих проверки (статус `pending`).
3. При нажатии «Одобрить» экскурсия меняет статус на `approved` и появляется в каталоге.
4. При нажатии «Отклонить» экскурсия не попадает в каталог.

## Критерии приёмки (проверено)
- [x] Дано: экскурсия ожидает проверки. Когда: я одобряю её. Тогда: она появляется в каталоге.
- [x] Дано: экскурсия ожидает проверки. Когда: я отклоняю её. Тогда: она не появляется в каталоге.

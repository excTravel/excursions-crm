# Реализация US-5: Страница экскурсии

## Задействованные компоненты
- Компонент: `App\Livewire\ExcursionShow`
- Представление: `resources/views/livewire/excursion-show.blade.php`

## Логика работы
1. Клиент нажимает на карточку в каталоге.
2. Открывается страница с подробным описанием.
3. Отображаются фотографии, стоимость, место проведения и доступные даты (расписание).

## Критерии приёмки (проверено)
- [x] Дано: я в каталоге. Когда: я нажимаю на экскурсию. Тогда: я вижу описание, стоимость и место.
- [x] Дано: у экскурсии есть расписание. Когда: я открываю её. Тогда: я вижу доступные даты.

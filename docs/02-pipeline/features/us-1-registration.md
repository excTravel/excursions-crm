# Реализация US-1: Регистрация клиента или гида

## Задействованные компоненты
- Контроллер: `App\Http\Controllers\Auth\RegisteredUserController`
- Модель: `App\Models\User`
- Представление: `resources/views/auth/register.blade.php`

## Логика работы
1. Пользователь заполняет форму регистрации (имя, email, пароль, роль).
2. Контроллер валидирует данные: поле `role` обязательно и должно быть `client` или `guide`.
3. Пароль хешируется с помощью `Hash::make()`.
4. Создаётся запись в таблице `users`.
5. Событие `Registered` вызывается для возможной отправки письма.
6. Пользователь автоматически авторизуется через `Auth::login($user)`.
7. Редирект на дашборд.

## Критерии приёмки (проверено)
- [x] Учётная запись создаётся при валидных данных.
- [x] При дубликате email выводится ошибка валидации.
- [x] Роль сохраняется в БД.

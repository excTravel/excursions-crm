# Отчет о производительности (ЛР3)

## Цель производительности
- p95 времени ответа ≤ 300 мс при 50 RPS.
- Доля ошибок < 1%.

## Базовая линия (до оптимизации)
- **Инструмент:** k6
- **Нагрузка:** 50 виртуальных пользователей, 2 минуты.
- **Результаты:**
  - **RPS:** 33.5
  - **p(95):** 235.68 ms
  - **Ошибки:** 0.00%

## Найденное узкое место
- **Проблема N+1** в компоненте `ExcursionsList` (задача TD-3 из реестра техдолга).
- При загрузке каталога выполняется слишком много запросов к базе данных (для каждой экскурсии отдельно подгружаются фото, категории и расписания).

## Оптимизация
- Добавлен жадный захват связей (eager loading) через `with()` в `ExcursionsList`.

# Отчет о качестве кода

## Цель
Зафиксировать метрики кода и настроить обязательную проверку порога качества в CI.

## Ход выполнения

### 1. Статический анализ (Larastan)
В проект добавлен пакет `larastan/larastan` (уровень 5). 
**Результат первого запуска:** обнаружено **70 ошибок**. 

Основные категории ошибок:
- `larastan.relationExistence` (связи Eloquent не описаны через PHPDoc).
- `property.notFound` (обращение к магическим свойствам моделей).
- `booleanAnd.alwaysTrue` (избыточные проверки).

**Порог качества (Quality Gate):**
С помощью `phpstan-baseline.neon` мы зафиксировали 70 существующих ошибок. Теперь CI пропускает этот унаследованный код, но **упадет, если в новом коде появится хотя бы одна ошибка**. Это фиксирует текущий технический долг и запрещает добавлять новые ошибки.

### 2. Сложность кода
Для контроля когнитивной сложности подключен пакет `squizlabs/php_codesniffer` с правилом `Generic.Metrics.CyclomaticComplexity`. В CI добавлен шаг `Check Code Complexity`. Порог сложности для новых функций установлен ≤ 10.

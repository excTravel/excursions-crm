# Оценки (Planning Poker)

## Цель
Зафиксировать размеры историй в story points по шкале Фибоначчи (1, 2, 3, 5, 8, 13) для расчёта WSJF, ёмкости и рюкзака.

## Исходные данные
18 пользовательских историй (US-1…US-18), шкала Фибоначчи, два участника: Ваня и Дамир.

## Ход
### Правило сведения
- Совпали → фиксируем.
- Расхождение ≤ 2 шагов → обсуждаем; если один игрок приводит конкретный риск — берём его оценку, иначе меньшую.
- Расхождение ≥ 3 шагов → берём оценку с обоснованным риском.

## Выводы
- MVP (US-1…US-11): 56 SP.
- Post-MVP (US-12…US-18): 36 SP.
- Всего: 92 SP.
- Расхождения в покере были по 13 историям; итог совпал с оценкой Дамира в 6 случаях, с оценкой Вани — в 12, что объясняется правилом «при прочих равных берём меньшую».

## Итог
Размеры зафиксированы. Следующий шаг — WSJF и рюкзак.

# План релиза и прогнозирование

## Цель
Оценить сроки завершения MVP с помощью Монте-Карло и определить критический путь проекта.

## Исходные данные
- Бэклог: 18 задач (US-1…US-18).
- История пропускной способности (5 недель): 2, 3, 2, 4, 3 задачи в неделю (среднее 2.8).
- Оценки O, M, P взяты из Planning Poker.

## Ход

### 1. Прогноз Монте-Карло
Метод симулирует 10 000 сценариев выполнения бэклога с учетом случайного колебания скорости команды.

**Результаты:**
- С вероятностью 50% бэклог будет выполнен за **7 недель**.
- С вероятностью 85% бэклог будет выполнен за **7 недель**.
- С вероятностью 95% бэклог будет выполнен за **8 недель**.

**Вывод:** Команда имеет высокую стабильность (разброс всего 5-8 недель). Однако для 85% вероятности нужно планировать 7 недель. Если сроки жесткие (например, защита через 4 недели), то команда не успевает закрыть весь бэклог, и нужно сокращать объём (см. рюкзак).

### 2. PERT и критический путь (pert_cpm.py)
Сетевой график построен на основе зависимостей. Скрипт рассчитал ожидаемое время (E) и дисперсию (σ) для каждой задачи.

**Критический путь:** US-1 → US-6 → US-7 → US-8 → US-3 → US-9 → US-10 → US-11.
**Ожидаемая длительность:** 46.83 дней. Стандартное отклонение: 3.05 дней.

**Вероятностные сроки:**
- С вероятностью 50%: 47 дней.
- С вероятностью 85%: 50 дней.
- С вероятностью 95%: 52 дня.
